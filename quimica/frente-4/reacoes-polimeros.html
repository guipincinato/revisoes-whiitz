Simples troca: quando ocorre?

Só se o elemento livre for mais reativo que o do composto. Fila de reatividade dos metais (maior → menor): Li, K, Ba, Ca, Na, Mg, Al, Mn, Zn, Cr, Fe, Co, Ni, Sn, Pb, H, Cu, Hg, Ag, Pt, Au. Ametais: F > O > Cl > Br > I > S.

  • Metais à esquerda do H deslocam H₂ de ácidos diluídos: Zn + 2HCl → ZnCl₂ + H₂. Cu, Ag e Au não (mas o Cu reage com HNO₃, que é oxidante).
  • Alcalinos e alcalinoterrosos (Li, K, Ba, Ca, Na) reagem com água fria: 2Na + 2H₂O → 2NaOH + H₂.

Dupla troca: quando ocorre?

Ocorre se algum produto for insolúvel (precipitado), volátil (gás) ou um eletrólito mais fraco (incluindo água). Instáveis que se decompõem: H₂CO₃ → H₂O + CO₂; H₂SO₃ → H₂O + SO₂; NH₄OH → NH₃ + H₂O.

  • Neutralização: ácido + base → sal + água. Total: H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O. Parcial (sal ácido): H₂SO₄ + NaOH → NaHSO₄ + H₂O. Parcial (sal básico): Ca(OH)₂ + HCl → Ca(OH)Cl + H₂O.
  • Ácido + carbonato: CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑ (efervescência; ataque do mármore pela chuva ácida).
Exercício. Há reação? (a) Cu + ZnSO₄: não (Cu é menos reativo que Zn). (b) Zn + CuSO₄ → ZnSO₄ + Cu: sim. (c) I₂ + NaCl: não (I é menos reativo que Cl). (d) BaCl₂ + Na₂SO₄: sim, forma BaSO₄ (insolúvel). (e) NaCl + KNO₃: não, todos os possíveis produtos (NaNO₃, KCl) são solúveis.

Balanceamento por tentativas: acerte nesta ordem: Metais, Ametais, Carbono, Hidrogênio, Oxigênio ("MACHO"). Para oxirredução, use o método do NOX.

Exercícios resolvidos

Exercício 1 · Neutralização total

Quantos mL de NaOH 0,2 mol/L neutralizam 200 mL de H₂SO₄ 0,1 mol/L?

Ver resolução passo a passo

1) n(H₂SO₄) = 0,1 × 0,2 = 0,02 mol. O H₂SO₄ é diácido: n(H⁺) = 2 × 0,02 = 0,04 mol.
2) Neutralização: n(OH⁻) = n(H⁺) = 0,04 mol (NaOH tem 1 OH⁻).
3) V = n/M = 0,04/0,2 = 0,2 L = 200 mL.

Polímeros

Macromoléculas formadas pela repetição de unidades pequenas, os monômeros. O nº de unidades é o grau de polimerização (n). Podem ser naturais (celulose, amido, proteínas, DNA, borracha natural) ou sintéticos.

Polimerização por adição

O monômero tem dupla C=C; a dupla se abre e as unidades se unem, sem perda de moléculas: n CH₂=CH₂ → (–CH₂–CH₂–)ₙ. Monômeros iguais: homopolímero; monômeros diferentes: copolímero.

Polimerização por condensação

Dois grupos funcionais reagem entre si e liberam moléculas pequenas (geralmente H₂O): os monômeros têm dois grupos reativos. Náilon 6,6: ácido adípico (HOOC–(CH₂)₄–COOH) + hexametilenodiamina (H₂N–(CH₂)₆–NH₂) → poliamida (ligação amida –CO–NH–) + H₂O. PET: ácido tereftálico + etilenoglicol → poliéster (ligação éster) + H₂O.
